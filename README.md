# Java Day 52 - Online Shopping Cart Management

## Description
A console-based online shopping cart application developed using Java OOP concepts and ArrayList.

## Features
- Display available products
- Add products to shopping cart
- Update quantity when adding an existing product
- View cart and calculate grand total
- Remove products from cart
- Checkout and save order details in a text file

## Files
- `Main.java` - Main Java program
- `orders.txt` - Order history, created automatically after checkout

## Requirements
- Java JDK

## How to Compile
```bash
javac Main.java
```

## How to Run
```bash
java Main
```

## Concepts Used
- Classes and Objects
- Constructors
- ArrayList
- Methods
- Exception Handling
- File Writing
